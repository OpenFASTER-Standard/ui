# @openfaster-standard/write-client

Part of [OpenFASTER](https://openfaster.org). A pure, framework-agnostic
module that commits a re-citation -- a corrected XPath selector on an
existing SHACL property shape, produced by
[`@openfaster-standard/shapes`](https://www.npmjs.com/package/@openfaster-standard/shapes)'s
`ReCitationPicker` -- via GitHub's Content API, client-side, with no
backend of its own.
