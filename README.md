# OpenFASTER UI

Part of [OpenFASTER](https://openfaster.org). A shared React component
library and Storybook catalogue meant to become the foundational UI for
every OpenFASTER tool, published publicly as
[`@openfaster-standard/ui`](https://www.npmjs.com/package/@openfaster-standard/ui) --
not built for or scoped to any single consumer, including
[`generator`](https://github.com/OpenFASTER-Standard/generator), its
first real one.

See `docs/specs/` for the full design record, one sub-project at a time.
